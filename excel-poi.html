Universal Excel POI

Apache POI ustida qurilgan fluent Java kutubxonasi. .xlsx fayllarni o'qish, yozish, uslublash, shablondan to'ldirish va katta fayllar bilan ishlash uchun mo'ljallangan.

API ataylab POI nomlariga yaqin qilingan:

  • XSSF: Excel.xssf() - XSSFWorkbook asosidagi xotirada ishlaydigan rejim. Workbook to'liq xotirada bo'ladi.
  • SXSSF/SAX: Excel.sxssf() - katta fayllarni yozish uchun SXSSFWorkbook, katta fayllarni o'qish uchun SAX parser ishlatadi.

Bu nomlar Java Stream API bilan adashmaslik uchun tanlangan.

Talablar

  • Java 25
  • Maven
  • Apache POI poi-ooxml

Maven

<dependency>
  <groupId>uz.rnr</groupId>
  <artifactId>excel-rnr</artifactId>
  <version>1.0.0</version>
</dependency>

Boshqa projectlarda dependency sifatida ishlatish

Avval kutubxonani local Maven repository'ga install qiling:

mvn -s maven-settings.xml "-Dmaven.repo.local=.m2\repository" clean install

Agar oddiy Maven local repository ishlatilsa:

mvn clean install

Keyin boshqa project pom.xml fayliga dependency qo'shing:

<dependency>
  <groupId>uz.rnr</groupId>
  <artifactId>excel-rnr</artifactId>
  <version>1.0.0</version>
</dependency>

Agar install paytida -Dmaven.repo.local=.m2\repository ishlatilgan bo'lsa, boshqa project build'ida ham shu local repository path berilishi kerak yoki artifact standart ~/.m2/repositoryga install qilinishi kerak.

try (var book = Excel.xssf().open(Path.of("input.xlsx"))) {
    List<Map<String, String>> rows = book.sheet(0)
            .includeEmptyRows(false)
            .rowsAsMaps(0);

            .customProp("version", "1");

}

XSSF va SXSSF o'rtasida konvertatsiya

Workbook'ni ikki tomonga ham o'tkazish mumkin:

  • XSSF -> SXSSF
  • SXSSF -> XSSF

XSSF workbook'dan SXSSF workbook'ga o'tish

1-usul: XssfWorkbook.toSxssf(Path).

try (var xssf = Excel.xssf().open(Path.of("input.xlsx"));
     var sxssf = xssf.toSxssf(Path.of("streamed.xlsx"))) {

    sxssf.sheet("Extra")
            .row("created in SXSSF mode")
            .save();
}

2-usul: Excel.sxssf().from(XSSFWorkbook).

try (var xssf = Excel.xssf().open(Path.of("input.xlsx"));
     var sxssf = Excel.sxssf().from(xssf.workbook()).to(Path.of("streamed.xlsx"))) {

    sxssf.sheet("Data")
            .row("new row")
            .save();
}

SXSSF workbook'dan XSSF workbook'ga o'tish

SxssfWorkbook.toXssf() joriy SXSSFWorkbook holatini ichki buffer'ga yozadi va uni XSSFWorkbook sifatida qayta ochadi.

try (var sxssf = Excel.sxssf().write().to(Path.of("tmp.xlsx"))) {
    sxssf.sheet("A").row("value");

    try (var xssf = sxssf.toXssf()) {
        xssf.sheet("A")
                .cell(1, 0, "edited in XSSF")
                .save(Path.of("xssf.xlsx"));
    }
}

Muhim: toXssf() katta SXSSF workbook'ni to'liq XSSF workbook'ga aylantiradi. Juda katta fayllarda bu ko'p xotira talab qiladi.

POI Row va Cell bilan missing policy orqali ishlash

XSSF rejimida, va imkon qadar SXSSF rejimida ham, row/cell olishda missing holatni aniq boshqarish mumkin.

TurQiymatVazifasi

SXSSF bo'yicha muhim cheklov: SXSSF eski row'larni diskka flush qilishi mumkin. Flush qilingan row poiRow(..., ERROR) uchun mavjud emas deb hisoblanadi; CREATE esa POI/SXSSF cheklovlariga bog'liq holda faqat ruxsat etilgan row indekslarida ishlaydi.

SXSSF poiRow(... CREATE) yoki poiCell(... CREATE) orqali row yaratilsa, keyingi fluent row(...) o'sha row ustiga yozib yubormasligi uchun ichki nextRowIndex avtomatik oldinga suriladi.

with... lambda metodlari

POI obyektlariga to'g'ridan-to'g'ri murojaat qilish kerak bo'lsa, with... metodlari chain'ni buzmasdan lambda bajaradi.

Joriy XSSF workbook bilan ishlash

try (var book = Excel.xssf().create()) {
    book.withWorkbook(wb -> wb.setForceFormulaRecalculation(true))
            .sheet("Data")
            .row(0, "ID", "Name");
}

XSSF sheet, row va cell bilan ishlash

try (var book = Excel.xssf().create()) {
    book.sheet("Data")
            .withSheet(sheet -> sheet.createFreezePane(0, 1))
            .withRow(0, MissingRowPolicy.CREATE,
                    RowCreateOptions.heightInPoints(24F),
                    row -> row.setZeroHeight(false))
            .withCell(
                    0,
                    0,
                    MissingRowPolicy.CREATE,
                    MissingCellPolicy.CREATE,
                    RowCreateOptions.defaults(),
                    CellCreateOptions.style(ExcelStyles.header()),
                    cell -> cell.setCellValue("ID")
            );
}

Joriy SXSSF workbook va sheet bilan ishlash

try (var out = Excel.sxssf().write().to(Path.of("out.xlsx"))) {
    out.withWorkbook(wb -> wb.setCompressTempFiles(true))
            .sheet("Data")
            .withSheet(sheet -> sheet.setColumnWidth(0, 20 * 256))
            .withCell(
                    0,
                    0,
                    MissingRowPolicy.CREATE,
                    MissingCellPolicy.CREATE,
                    cell -> cell.setCellValue("created with lambda")
            )
            .save();
}

Built-in style nomlari:

  • __header: bold + thin borders.
  • __integer: #,##0 format.
  • __decimal: #,##0.00 format.
  • __date: dd.mm.yyyy format.

row(...) qiymat turiga qarab built-in style'ni avtomatik qo'llaydi:

  • Integer, Long -> integer style
  • BigDecimal, Float, Double -> decimal style
  • LocalDate, LocalDateTime, Date, Calendar -> date style

SXSSF row limit va avtomatik yangi sheet

SxssfWorkbook.row(...) yozish jarayonida joriy sheet Excel.MAX_ROWS limitiga yetsa, kutubxona avtomatik yangi sheet yaratadi va yozishni davom ettiradi. Yangi sheet nomi bazaviy nomdan olinadi:

  • Data
  • Data_2
  • Data_3

Yangi sheet avtomatik yaratilganda callback ishlatish uchun onAutoCreateNewSheet(...) metodidan foydalaning.

try (var out = Excel.sxssf().write().to(Path.of("large.xlsx"))) {
    out.sheet("Data")
            .onAutoCreateNewSheet(sheet -> {
                sheet.createFreezePane(0, 1);
                sheet.setColumnWidth(0, 20 * 256);
            });

    for (long i = 0; i < (long) Excel.MAX_ROWS + 10; i++) {
        out.row(i, "Name " + i);
    }

    out.save();
}

onAutoCreateNewSheet(Consumer<? super Sheet> handler) faqat row limit sabab avtomatik ochilgan sheet uchun ishlaydi. Qo'lda sheet("...") chaqirilsa, bu callback ishlamaydi.

        .writeFromTemplate(Path.of("template.xlsx"))
        .sheet(0)
        .headerLastRow(0)
        .dataStartRow(1)
        .dataColumns(0, 3)
        .summaryRow(10)
        .rows((globalRow, sheetIndex, rowIndex) -> {
            if (globalRow > 1_000) {

            }

Ichki ishlash tartibi:

  • dataStartRowdan boshlangan mavjud row'lar tozalanadi.
  • Style'lar template data row yoki column style'dan olinadi.
  • Excel row limit to'lsa yangi sheet yaratiladi.
  • Yangi sheet'larga header row'lar, column width va header merged region'lar ko'chiriladi.
  • summaryRow berilgan bo'lsa, A2:A10 ko'rinishidagi formula range'lari haqiqiy data range'ga moslanadi.

Amaliy tavsiyalar

  • Kichik va o'rtacha fayllarni tahrirlash uchun Excel.xssf() ishlating.
  • Katta fayllarni o'qish uchun Excel.sxssf().read(...) ishlating.
  • Katta fayllarni yozish uchun Excel.sxssf().write() ishlating.
  • Tayyor Excel shablonini style va layout bilan saqlab to'ldirish kerak bo'lsa writeFromTemplate(...) ishlating.
  • toXssf() SXSSF workbook'ni XSSF workbook'ga aylantiradi, shuning uchun juda katta fayllarda ehtiyotkorlik bilan ishlating.
